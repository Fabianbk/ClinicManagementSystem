# Document Templates

วางไฟล์ Word Template (`.docx`) ที่จัดแท็กเรียบร้อยแล้วไว้ที่โฟลเดอร์นี้:

1. `client_intake_form.docx` - สำหรับแบบบันทึกข้อมูลผู้รับบริการและประวัติการรักษา (ครอบคลุมทั้ง 6 หน้า)
2. `treatment_order.docx` - สำหรับใบสั่งการรักษาแยกเฉพาะ (หน้า 5)

ดูคู่มือชื่อตัวแปร (Tags) และวิธีจัดหน้าได้จากเอกสารคำแนะนำในแชต
